## 500Mbps 是端口速率，500GB 才是月流量

这是选 VPS 时最容易看错的一处。宣传页上写的 500Mbps 指的是网卡端口上限，不是每月可用流量。A1 mini 的月流量是 500GB，跑满了端口大约一小时就能烧掉一大半流量。

500GB 摊到每天约 16GB。个人博客、小型企业站、API 服务这类以文本为主的业务，一个月通常用不掉十分之一。如果要做视频中转、镜像站、大文件下载，这个流量就不够看了，得直接看 2TB 那档。

另外两个容易忽略的点：

**10GB 系统盘偏紧。** 装完 Linux 系统和运行环境，通常还剩 6 到 7GB。日志、数据库、备份文件都要占地方，建议在系统里配好日志轮转，别让站点跑两个月把盘写满。

**512MB 内存要算清楚。** 跑 Nginx 加 PHP 加 MySQL 的组合，512MB 属于勉强。换用 SQLite 或者静态站点生成器，这档就很宽裕。这也是为什么多数人会从 ¥299 那档起步试水，稳定之后再升到 ¥449 或 ¥699。
